EcoApp is a mobile application designed to encourage textile recycling through a simple incentive system. Users can scan QR codes at recycling bins, register their drop-offs, and earn points for properly sorting garments into the correct containers.

The system consists of two main components:

iOS application (SwiftUI) – user interface, QR scanning, and interaction with the API

Backend API (FastAPI + PostgreSQL) – authentication, recycling center management, and drop-off tracking
